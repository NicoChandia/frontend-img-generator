      ¿Cómo funciona?
      1. Frontend estático (HTML, CSS y JS, sin frameworks) publicado en GitHub Pages.
      2. API en Flask desplegada en Render: recibe el prompt, guarda el token de Hugging Face del lado del servidor y solo acepta pedidos de este dominio (CORS).
      3. Modelo FLUX.1-schnell (Black Forest Labs, licencia Apache 2.0): genera una imagen en solo 1 a 4 pasos, por eso responde en segundos.
      4. Hugging Face Inference Providers con selección automática de proveedor: si un proveedor deja de servir el modelo, la API sigue funcionando sin cambiar el frontend.
